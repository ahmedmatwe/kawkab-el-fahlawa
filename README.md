# كوكب الفهلوة — استوديو إنتاج آلي مجاني

> هنا كل مشكلة ليها حل… وكل حل وراه مصيبة!

استوديو بيشتغل على السحابة (GitHub Actions) والماك مقفول، وتكلفته **صفر**:

```
كل 15 دقيقة:  قراءة ردودك على تليجرام → (الصبح) ترندات مصر + 3 أفكار → إنتاج الحلقة المختارة
الفكرة ✅ ← سيناريو مصري + مراجعة (إعادة كتابة لو ضعيف) ← مراجعة سلامة ← ستوري بورد
← أول فريم من صور الشخصيات المعتمدة + أصوات ثابتة لكل شخصية ← توليد اللقطات على Kaggle GPU المجاني
← فحص كل لقطة (تلف/مقاس/تغير الشكل) وإعادة توليد الفاشل ← مونتاج 1080×1920 + كابشن عربي + صوت -14 LUFS
← فحوص الجودة (من 100) ← الفيديو يوصلك تليجرام: ✅ اعتمد / 🔁 أعد / ❌ ارفض ← حزمة نشر يدوي
```

## المكونات المجانية
| الجزء | الأداة | الحد المجاني |
|---|---|---|
| التشغيل | GitHub Actions | مستودع عام: بلا حد · خاص: 2000 دقيقة/شهر |
| الكتابة والمراجعة | Gemini API (مفتاح من AI Studio) | الباقة المجانية |
| الفيديو | Wan 2.2 TI2V-5B (مفتوح المصدر) على Kaggle | ~30 ساعة GPU/أسبوع |
| الأصوات | edge-tts (شاكر وسلمى المصريين) | مجاني |
| المونتاج والكابشن | FFmpeg + خط Cairo (OFL) | مجاني |
| التحكم | بوت تليجرام | مجاني |

## أوامر تليجرام
`ابدأ` (أول فكرة) · `غير` (أفكار جديدة) · `فكرة …` (فكرتك انت) · `حالة`

## تشغيل محلي
```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
STUDIO_MODE=demo .venv/bin/python -m studio demo      # حلقة تجريبية كاملة بمزود وهمي (عليها DEMO)
STUDIO_MODE=demo .venv/bin/python -m pytest -q        # الاختبارات الإلزامية
.venv/bin/python -m studio agents                     # الفريق وحالة كل وكيل
```

## الشخصيات
`config/characters.json` هو المرجع المعتمد (الشكل، الإفيهات، الصوت، الصور). الصور المعتمدة في
`assets/characters/refs/` ومقصوصة من البوسترين بـ `scripts/crop_refs.py`. أي صورة جديدة لازم تعتمدها انت قبل ما تتضاف.

## حدود معروفة (بصراحة)
- مزامنة الشفايف الحقيقية مش موجودة لسه (الوكيل A15)؛ الشخصية بتتحرك وهي بتتكلم بس مش مطابقة للحروف.
- فحص ثبات الشخصية لوني بسيط؛ التغيرات الدقيقة في الوش محتاجة عينك في المعاينة.
- النشر التلقائي مقفول افتراضيًا؛ كل منصة بتوصلك كحزمة MANUAL_PUBLISH_REQUIRED لحد ما تربط الحسابات.
- التحليلات وتحليل التعليقات (A25، A26) محتاجين ربط الحسابات الأول.
